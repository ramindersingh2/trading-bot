Prompt Composition

  • • Section 1: Role — static, loaded once
  • • Section 2: Market data — fresh every run
  • • Section 3: News — fresh every run (3 days)
  • • Section 4: History — last 15 plans (full) + all-time trade summary
  • • Section 5: Task — static template, tells LLM exactly what to output

Data Storage Strategy

  • • plans.jsonl — append-only log of every LLM plan
  • • trades.jsonl — append-only log of every trade
  • • portfolio.json — rewritten each run with live state
  • • market_snapshots.jsonl — archive of hourly market data
  • • All files are plain JSON — easy to inspect, debug, audit

Risk Guardrails (in code)

  • • Max single trade: 10% of portfolio ($10k)
  • • Max open positions: 5 at a time
  • • Daily loss limit: $3,000 (stop trading)
  • • Always use limit orders, never market orders
  • • Block executes in Python — LLM cannot override
